# onsite

Open a project folder on your own computer and your always-on Hermes
works in it.

This folder is the plugin. It is all that an install puts on your
machine. The guide, the limits, what it touches and how it was tested
are on the site and in the repository:

- <https://saxby-tools.github.io/hermes-onsite/>
- <https://github.com/saxby-tools/hermes-onsite>

Set it up with `hermes onsite init`, or in Settings in Hermes Desktop.
